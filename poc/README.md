# Local-lab reproduction

## Static verification

```bash
python3 static_verify.py /path/to/laradashboard
```

The verifier only inspects source markers and does not modify the checkout.

## Harmless SVG marker

`marker.svg` contains an `onload` handler that changes text inside the SVG and sets the URL fragment to `XSS_MARKER`. It does not access cookies, storage, CSRF tokens, or external hosts.

## Upload in a disposable loopback lab

```bash
python3 upload_marker.py \
  --base-url http://127.0.0.1:8000 \
  --cookie 'laravel_session=REPLACE_ME' \
  --csrf 'REPLACE_ME' \
  --execute
```

Open the returned media URL manually in the same disposable lab. Execution is confirmed when the SVG displays `SCRIPT EXECUTED` and the URL fragment becomes `#XSS_MARKER`.

The original disclosure observed HTTP `200`, creation of a media record, inline `Content-Type: image/svg+xml`, and browser execution. Those are historical results from the published advisory, not output generated by this repository.
